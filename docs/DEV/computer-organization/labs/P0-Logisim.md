# P0-Logisim

## 课下

同步复位和异步复位的设计

- reset 为 1 时，同步复位在上升沿将 0 赋值给寄存器

寄存器赋初值

- 计数器计数，选择赋值初始信息/ `next_state` 计算信息
- 另有异或连法，见 Logisim 笔记

状态机

- Moore 型和 Mealy 型状态机的输出本质上都是由状态决定的
- Moore 型状态机根据当前状态来输出，计算下一个状态，下一个周期再赋值 next_state。测试的时候先 input，再 clk
- Mealy 状态机，当前状态+输入→次态，得到次态对应的 output。先 clk (正确地进行状态转移后)，再 input (算次态)
