# 文章编写

## 创建

在某一文件夹下创建 `.md` 文件，同时创建 `image` 文件夹，便于插入图片

## 部署

进入虚拟环境：

```bash
cd desktop/material-chasetsai
python3 -m venv venv
source venv/bin/activate
```

预览：

```bash
mkdocs serve
```

部署：

```bash
mkdocs gh-deploy --force
```

退出：

```bash
deactivate
```
